# Dopasowanie dekompilacji

- Jedyną raportowaną miarą dopasowania jest dystans Levenshteina między
  sekwencjami instrukcji MIPS, po uwzględnieniu relokacji.
- Nie raportuj liczby różniących się bajtów, słów ani linii jako miary postępu.
- Po osiągnięciu dystansu 0 potwierdź również zgodność pełnego EXE z oryginałem.
