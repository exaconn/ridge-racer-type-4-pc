[CHANGELOG.md](../CHANGELOG.md).

- [Linux — ARM64](https://github.com/khasinski/ridge-racer-type-4-pc/releases/download/<version>/Ridge-Racer-Type-4-<version>-linux-arm64.tar.gz)

Extract the download and select your own **European (PAL) disc image** of
*Ridge Racer Type 4* (CUE/BIN) when the game asks for it. Keep the CUE beside
its BIN. Game data is not included.

**Enter** is Start. **Escape** opens settings (graphics, controls, audio and
the disc image). Arrows steer, `X` accelerates (Cross), `Z` brakes (Square).

This is an early alpha; Windows is experimental. Checksums are in `SHA256SUMS`.

[Full changelog](https://github.com/khasinski/ridge-racer-type-4-pc/blob/<version>/CHANGELOG.md)
